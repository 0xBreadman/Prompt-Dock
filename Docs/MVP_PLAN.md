# MVP 实施规划

## 第一阶段：快捷面板（当前版本）

- [x] 原生 macOS App 工程
- [x] 始终置顶、可调整大小、可拖动的悬浮面板
- [x] 菜单栏常驻与全局快捷键呼出/隐藏
- [x] 分类浏览、基础搜索
- [x] 点击卡片复制完整 Prompt，并显示成功状态
- [x] 本地 JSON 保存、窗口位置和透明度记忆
- [x] 毛玻璃、圆角卡片、深色模式
- [x] 完整 Prompt 库管理后台
- [x] 多工作预设及面板快速切换
- [x] 每个预设独立的 6 槽位按键转盘
- [x] 可选择左右侧的屏幕边缘快捷栏
- [x] 交互预览与开关设置

验收标准：离线启动后能看到本地 Prompt；打开其他 App 时面板保持在上方；一次点击能将完整正文放入剪贴板；重启后数据仍存在。

## 第二阶段：管理与备份

- 子分类层级展示
- 拖动排序
- [x] JSON 导入、导出、每日快照和恢复
- [x] 全局快捷键冲突提示与自定义

验收标准：所有破坏性操作都有确认或撤销；导出后可在全新数据目录完整恢复；管理模式与日常快捷模式明确分离。

## 第三阶段：同步基础

- SwiftData Repository
- iCloud/CloudKit 私有数据库同步
- 冲突合并、离线缓存、同步状态
- 继续保留可读 JSON 备份

## 商业化扩展层

- Marketplace Repository：模板市场与只读订阅库
- Team Repository：角色、共享库和版本历史
- Provider Adapter：ChatGPT、Gemini、Grok 等调用适配
- Entitlement Service：免费版、Pro 与团队权限

这些扩展通过新 Repository/Service 接入，不让远端状态侵入卡片 UI 和本地复制主流程。
