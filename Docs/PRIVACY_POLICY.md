# Prompt Dock 隐私说明

更新日期：2026-08-11

Prompt Dock 是一款本地优先的 macOS Prompt 快捷工具。

## 数据处理

- Prompt 正文、分类、标签、工作预设和使用记录默认只保存在用户的 Mac 本机。
- 当前版本不要求注册账号，不接入广告，不使用第三方分析 SDK。
- 当前版本不会把 Prompt 内容上传到开发者服务器或第三方 AI 服务。
- 用户主动使用“导出 JSON”时，数据只会写入用户通过系统文件面板选择的位置。
- 用户主动使用“导入并恢复”时，App 只读取用户明确选择的 JSON 文件。

## 系统能力

- App 使用系统剪贴板写入用户主动选择的 Prompt。
- App 使用全局快捷键呼出悬浮面板和 Prompt 转盘。
- App 在自己的沙盒 Application Support 目录保存资料库与每日备份。

## 删除数据

用户可以在 App 内删除 Prompt、分类和工作预设。卸载 App 后，如需彻底删除本地数据，可同时删除 macOS 为 App 创建的沙盒容器。

## 未来功能

如果未来增加 iCloud、团队共享、AI 调用或分析功能，本说明会在功能上线前更新，并在 App 内明确说明相应的数据用途。

## 问题反馈

可以通过项目的 GitHub Issues 反馈一般问题。请勿在公开 Issue、截图或日志中提交私人 Prompt、API Key、账号信息或客户数据。安全问题请参阅仓库根目录的 `SECURITY.md`。
